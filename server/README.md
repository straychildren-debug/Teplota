# Приём заявок с формы

Сайт живёт на GitHub Pages — статика, без серверного кода. Поэтому приём
заявок вынесен наружу: форма отправляет запрос на отдельный обработчик,
а тот кладёт заявку в Telegram. Токен бота остаётся на сервере и в браузер
не попадает никогда.

```
teplota.su (Pages)  ──POST──>  обработчик  ──>  Telegram
```

Обработчик на другом домене, поэтому доступ открывается заголовками CORS —
он принимает запросы только с адресов из своего списка.

## Рабочий вариант: `yandex-function/`

Yandex Cloud Function. Домен от Яндекса, доступен из России, HTTPS из
коробки. Бесплатного лимита (1 000 000 вызовов в месяц) хватает с
тысячекратным запасом. Внешних зависимостей у функции нет — код
вставляется в редактор в консоли одним файлом.

Настройка описана в `yandex-function/SETUP.md`.

## Запасной вариант: `php/`

Обработчик на обычном PHP-хостинге, если понадобится переехать.
Работает на любом shared-хостинге, сборка не нужна.

Не подошёл сразу по двум причинам, обе всплыли на бесплатном тарифе
SpaceWeb: домен `*.swtest.ru` помечен Google Safe Browsing как опасный
(проблема родительского домена, не аккаунта), и на бесплатном плане там
запрещена отправка почты скриптами, то есть запасной канал не работал бы.

Если будете возвращаться к PHP — берите платный тариф и свой поддомен
вида `form.teplota.su`, тогда обе проблемы снимаются. Инструкция — в
комментариях внутри `php/send.php` и `php/config.sample.php`.

## Где прописан адрес обработчика

`public/js/app.js`, константа `FORM_ENDPOINT` в начале файла. После смены
адреса пересоберите страницу: `npm run page`.

Если очистить `FORM_ENDPOINT`, форма перейдёт на запасной путь — откроет
почтовый клиент посетителя с готовым письмом. Тот же путь включается сам,
если обработчик отвечает 404: заявка не теряется и ошибку посетитель не
видит.

## Коды ошибок

Наружу обработчик отдаёт только код, подробности пишет в свой лог.

| Код | Что означает |
|---|---|
| `forbidden_origin` | домен сайта не совпал со списком разрешённых — сверьте символ в символ, без слэша на конце |
| `bad_phone` | в телефоне меньше 10 цифр |
| `bad_request` | тело запроса не разобралось как JSON |
| `too_many` | превышен лимит заявок с одного адреса за час |
| `not_configured` | не заданы токен или chat_id |
| `upstream` | Telegram не ответил — смотрите лог обработчика |
