# Обработчик заявок на SpaceWeb

Сайт живёт на GitHub Pages, а форма отправляет заявку сюда — на отдельный
хостинг с PHP. Так токен бота остаётся на сервере и никогда не попадает
в браузер.

```
teplota.su (Pages)  ──POST──>  maratismag.temp.swtest.ru/send.php  ──>  Telegram
```

## Что залить на хостинг

В корень сайта, туда же, где `index.html` хостинга:

| Файл | Зачем |
|---|---|
| `send.php` | сам обработчик |
| `config.php` | ваши настройки, делается из `config.sample.php` |
| `check.php` | разовая проверка, после неё удалить |

`config.php` в репозитории нет и не должно быть — в нём токен. Он уже
добавлен в `.gitignore`.

## Порядок настройки

**1. Проверить хостинг.** Залейте `check.php`, откройте
`https://maratismag.temp.swtest.ru/check.php`. Он покажет версию PHP,
наличие cURL и mbstring, работает ли HTTPS и доходит ли
`api.telegram.org` с этого сервера. **После проверки файл удалите.**

**2. Узнать chat_id.** Напишите боту любое сообщение, затем откройте
`https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и найдите
`"chat":{"id":...}`. Для группы — сначала добавьте туда бота.
Ссылку с токеном никому не показывайте.

**3. Заполнить конфиг.** Скопируйте `config.sample.php` в `config.php`,
впишите токен и chat_id. Если проверка на шаге 1 показала, что Telegram
недоступен, поставьте `'channel' => 'email'`.

**4. Проверить форму.** Откройте сайт, отправьте заявку. Должен прийти
экран «Заявка принята», а в Telegram — сообщение.

## Если что-то не так

Обработчик наружу отдаёт только код ошибки, подробности пишет в лог
хостинга (раздел «Логи» в панели SpaceWeb).

| Что видно | Что означает |
|---|---|
| `not_configured` | нет `config.php` рядом с `send.php` |
| `forbidden_origin` | домен сайта не совпал со списком `allowed_origins` — сверьте символ в символ, без слэша на конце |
| `bad_phone` | телефон короче 10 цифр |
| `too_many` | больше 10 заявок в час с одного адреса |
| `upstream` | Telegram и почта оба не ответили — смотрите лог |
| форма открыла почтовый клиент | обработчик недоступен (404) — проверьте адрес в `public/js/app.js` |

Отдельно: страница на Pages отдаётся по HTTPS, поэтому и обработчик
обязан быть на HTTPS. Если `check.php` покажет, что HTTPS не работает,
включите SSL в панели хостинга — иначе браузер заблокирует запрос.

## Где прописан адрес обработчика

`public/js/app.js`, константа `FORM_ENDPOINT` в начале файла. Смените
её, если поменяется домен, и пересоберите страницу: `npm run page`.

Если очистить `FORM_ENDPOINT`, форма перейдёт на запасной путь —
откроет почтовый клиент посетителя с готовым письмом.
