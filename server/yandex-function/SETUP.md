# Настройка функции в Yandex Cloud

Займёт минут десять. Всё делается в браузере, ничего устанавливать не нужно.

## 1. Узнать chat_id

Куда бот будет слать заявки.

1. Напишите своему боту любое сообщение. Если заявки должны падать в
   группу — сначала добавьте бота в неё и напишите там.
2. Откройте в браузере:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. Найдите в ответе `"chat":{"id":...}`. Это число и есть chat_id.
   У групп он отрицательный, со знаком минус — минус тоже нужен.

Ссылку с токеном никому не показывайте и в закладки не сохраняйте.

Если ответ пустой (`"result":[]`) — значит бот сообщений не видел:
напишите ему ещё раз и обновите страницу.

## 2. Создать функцию

1. Откройте [console.yandex.cloud](https://console.yandex.cloud), войдите
   в свой каталог.
2. Найдите сервис **Cloud Functions**, нажмите **Создать функцию**.
3. Имя — например `teplota-lead`. Создать.

## 3. Загрузить код

1. Среда выполнения — **Node.js**, самая свежая из предложенных. Продолжить.
2. Способ — **Редактор кода**.
3. В файл `index.js` вставьте содержимое `index.js` из этой папки,
   заменив то, что там было по умолчанию.
4. **Точка входа**: `index.handler` — именно так, это важно.
5. Таймаут — `15` секунд. Память — `128` МБ, больше не нужно.

## 4. Переменные окружения

Здесь же, в блоке переменных окружения, добавьте три штуки:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `TELEGRAM_CHAT_ID` | число из шага 1 |
| `ALLOWED_ORIGINS` | `https://teplota.su,https://www.teplota.su` |

`ALLOWED_ORIGINS` — через запятую, без пробелов и без слэша на конце.
Браузер сверяет адрес символ в символ.

Токен живёт только здесь. В репозиторий он не попадает.

## 5. Сделать функцию публичной

Поставьте галочку **Публичная функция** — иначе сайт не сможет к ней
обратиться. Сохраните изменения: создастся версия функции.

## 6. Забрать адрес

На странице функции найдите **Ссылку для вызова** — вида
`https://functions.yandexcloud.net/d4e...`

Пришлите её мне: я пропишу адрес в форме и пересоберу страницу.
Секрета в этой ссылке нет — она защищена списком разрешённых доменов
и без токена внутри функции всё равно ничего не отправит.

## Проверка

После того как адрес будет прописан в форме: откройте сайт, отправьте
заявку. Должен появиться экран «Заявка принята», а в Telegram — сообщение.

Если не пришло — в консоли у функции есть вкладка с логами, там будет
причина. Наружу функция подробности не отдаёт намеренно.

## Сколько это стоит

Бесплатный лимит — 1 000 000 вызовов и 10 ГБ×час в месяц. Форма на сайте
даёт порядок десятков вызовов в месяц, то есть в лимит вы не упрётесь.
Карта привязана для идентификации, а не для списаний.
